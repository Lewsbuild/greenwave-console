Help & Quick Guide

Guides are kept here so the console stays uncluttered.

Getting started

  1. Select a mixer profile to choose a channel layout.
  2. Tap Start audio to initialize audio playback.
  3. Import an audio file in Music Player.
  4. Open a channel to adjust its settings and routing.
  5. Save a scene to export your current settings as a JSON file.

Channel controls

  • Fader: changes channel level in the session.
  • Mute / Solo: controls local playback for supported audio inputs.
  • Pan: positions audio between left and right.
  • Gate / Compressor / EQ: configure the selected channel processing.
  • Routing: enable Main L/R or AUX 1–6 destinations.

Offline use & installation

Save this HTML file to your device and open it in a modern browser. For an installable offline website, deploy it with HTTPS on GitHub Pages, then use your browser’s “Add to Home screen” or “Install app” option. A service worker needs a separate file for reliable offline caching; this standalone HTML works locally after it is saved.

Real hardware connection

This app currently runs as a local software console and audio player. The mixer profile selector changes the available software layout; it does not establish a physical mixer connection. Real remote control requires a compatible mixer, network setup, and implementation of that model’s protocol.

Always test audio at low volume first and avoid feedback or unexpectedly loud outputs.
